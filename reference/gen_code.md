# Generate R code for a specific alternative branch

Generate R code for a specific alternative branch

## Usage

``` r
gen_code(
  base_schema,
  base_code,
  alternatives,
  output_dir = "scripts",
  provider = "gemini"
)

prompt_code(print = FALSE)
```

## Arguments

- base_schema:

  The original schema object or file path.

- base_code:

  The file path to the original R script.

- alternatives:

  A single alternative object (list with tag, decision, etc.).

- output_dir:

  The directory where the generated R script will be saved. Defaults to
  "scripts".

- provider:

  The LLM provider to use for code generation. Currently only "gemini".

- print:

  A logical. If \`TRUE\`, the prompt generated by
  \`prompt_alternatives()\` will be printed to the console in a readable
  format. Default to \`FALSE\`

## Examples

``` r
if (FALSE) { # \dontrun{
hdi <- example_schema()
gen_code(hdi,
         base_code = system.file("hdi.R", package = "tines"),
         alternative = system.file("hdi-alt.yaml", package = "tines"),
         output_dir = here::here("inst/"))
} # }
```
